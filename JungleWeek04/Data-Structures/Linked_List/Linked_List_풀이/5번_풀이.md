# **단방향 연결 리스트 앞/뒤 절반 분리(`frontBackSplitLL`) 구현**

## **1. 문제 요구사항**

* **기능**: 하나의 단방향 연결 리스트를 **앞쪽 절반(`frontList`)과 뒤쪽 절반(`backList`)으로 나눈다.**

* **조건**:

  * 원래 연결 리스트의 노드들을 앞쪽과 뒤쪽 두 개의 리스트로 나눈다.
  * 노드의 개수가 **홀수인 경우 앞쪽 리스트에 노드를 한 개 더 포함**한다.
  * 기존 노드를 이용하여 두 리스트로 분리한다.
  * `frontList`와 `backList`를 각각 출력할 수 있도록 결과 리스트의 `head`를 설정한다.

* **예시**:

```text
기존 리스트

2 → 3 → 5 → 6 → 7


분리 결과

frontList
2 → 3 → 5 → NULL

backList
6 → 7 → NULL
```

예를 들어 노드가 5개라면 앞쪽 리스트에 3개, 뒤쪽 리스트에 2개가 들어간다. 문제에서도 홀수 개수일 때 남는 노드를 front list에 넣도록 요구하고 있다. 

---

## **2. 시행착오 과정**

### **1차 시도: 노드가 존재하지 않는 빈 리스트에 접근**

처음에는 결과 리스트의 `head`에 기존 노드의 값을 넣어주려고 했다.

```c
ListNode *frontP = resultFrontList->head;
ListNode *backP = resultBackList->head;
ListNode *start = ll->head;

int idx = 0;
int size = sizeof(ll);
int mid = size / 2;

while (idx <= mid) {
    resultFrontList->head->item = start->item;
    idx++;
    start = start->next;
}
```

실행하자 `EXC_BAD_ACCESS`가 발생했다.

#### **원인 1: `resultFrontList->head`가 NULL**

`resultFrontList`는 처음에 비어 있는 리스트이기 때문에 `resultFrontList->head`가 `NULL`이다.

그런데

```c
resultFrontList->head->item = start->item;
```

처럼 `NULL`인 포인터를 통해 `item`에 접근하려고 했기 때문에 오류가 발생했다.

즉, 단순히 `item`의 값을 복사하는 것이 아니라 **기존 노드를 가리키는 포인터를 이용해서 리스트를 연결해야 한다.**

---

#### **원인 2: `sizeof(ll)`은 리스트의 크기가 아님**

```c
int size = sizeof(ll);
```

여기서 `ll`은 `LinkedList *`이므로 `sizeof(ll)`은 리스트에 들어있는 노드 개수가 아니라 **포인터 자체의 크기**를 반환한다.

따라서 실제 리스트의 크기를 구하려면

```c
int size = ll->size;
```

처럼 리스트에 저장된 `size`를 사용해야 한다.

---

#### **원인 3: `mid`와 반복 조건의 문제**

처음에는

```c
int mid = size / 2;

while (idx <= mid)
```

로 작성했다.

그런데 `idx <= mid`는 `mid + 1`번 반복하기 때문에 리스트의 크기가 짝수일 때 원하는 개수보다 하나 더 들어가게 된다.

그래서 **앞쪽 리스트에 들어갈 개수 자체를 `(size + 1) / 2`로 계산하고, `idx < mid`로 반복**하는 방식으로 수정했다.

```c
int mid = (size + 1) / 2;

while (idx < mid)
```

예를 들어:

```text
size = 5

mid = (5 + 1) / 2
    = 3

idx < 3

0 → 1 → 2
총 3번 반복
```

따라서 `2, 3, 5`가 front list에 들어간다.

---

### **2차 시도: `resultFrontList->head`를 계속 검사하는 문제**

앞쪽 리스트를 만드는 부분을 다음과 같이 수정했다.

```c
int idx = 0;
int size = ll->size;
int mid = (size + 1) / 2;

while (idx < mid) {
    if (resultFrontList->head == NULL) {
        frontP = start;
        tailP = start;
    } else {
        tailP->next = start;
        tailP = start;
    }

    idx++;
    start = start->next;
}
```

처음에는 `resultFrontList->head == NULL`을 검사하면 된다고 생각했다.

그런데 이 조건은 반복문이 끝날 때까지 계속 `NULL`이다.

왜냐하면 반복문 안에서 실제로 변경하는 것은

```c
frontP = start;
```

이고,

```c
resultFrontList->head
```

자체는 변경하지 않았기 때문이다.

따라서 매번

```c
if (resultFrontList->head == NULL)
```

이 참이 되어 `frontP`가 계속 새로운 `start`로 덮어써지게 된다.

그래서 결과 리스트의 첫 번째 노드를 의미하는 `head`와, 현재 작업 중인 포인터인 `frontP`를 분리해서 생각해야 했다.

```c
if (frontP == NULL) {
    frontP = start;
    frontTailP = start;
} else {
    frontTailP->next = start;
    frontTailP = start;
}
```

그리고 모든 노드를 연결한 뒤 마지막에

```c
resultFrontList->head = frontP;
```

를 통해 실제 결과 리스트의 `head`를 설정한다.

---

### **`frontP`와 `resultFrontList->head`의 관계**

처음에는 둘 다 `NULL`이다.

```text
resultFrontList->head → NULL
frontP               → NULL
```

첫 번째 노드를 발견하면:

```c
frontP = start;
```

가 실행되어 `frontP`는 기존 리스트의 첫 번째 노드를 가리키게 된다.

```text
resultFrontList->head → NULL

frontP
  ↓
2 → 3 → 5 → 6 → 7
```

이때 `resultFrontList->head`는 여전히 `NULL`이다.

따라서 반복문이 끝난 뒤

```c
resultFrontList->head = frontP;
```

를 실행해야 한다.

```text
resultFrontList->head
        ↓
2 → 3 → 5
```

즉, **`frontP`로 실제 노드를 연결하고, 마지막에 `resultFrontList->head`에 그 시작 주소를 넣어주는 것**이다.

---

### **3차 시도: front list는 잘렸지만 back list가 비어 있는 문제**

앞쪽 리스트를 연결한 후 마지막 노드의 연결을 끊기 위해

```c
if (frontTailP != NULL) {
    frontTailP->next = NULL;
}
```

을 추가했다.

그러자 front list는 정상적으로

```text
2 → 3 → 5 → NULL
```

처럼 잘렸다.

그런데 back list가 빈 상태로 출력됐다.

back list 역시 `backP`라는 로컬 포인터에 노드를 연결하고 있었지만, 마지막에 실제 `resultBackList->head`에 연결하지 않았기 때문이었다.

즉,

```c
backP = start;
```

만 해서는 `resultBackList`의 시작점이 바뀌지 않는다.

front list에서 했던 것처럼 마지막에

```c
resultBackList->head = backP;
```

를 추가해야 한다.

---

## **3. 깨달음**

### **1. `Head`와 실제 작업용 포인터를 구분해야 한다**

```text
frontP      → front list의 첫 번째 노드를 가리키는 포인터
frontTailP  → front list의 마지막 노드

backP       → back list의 첫 번째 노드를 가리키는 포인터
backTail    → back list의 마지막 노드
```

처음부터 `resultFrontList->head`를 직접 조작하는 것이 아니라, 포인터 변수로 노드들을 연결한 다음 마지막에 `head`를 설정한다.

---

### **2. `Head`와 `Tail`을 함께 사용해야 한다**

첫 번째 노드를 추가할 때는:

```c
frontP = start;
frontTailP = start;
```

그 이후에는:

```c
frontTailP->next = start;
frontTailP = start;
```

이렇게 해야 새로운 노드를 마지막에 연결하고 `Tail`도 새로운 마지막 노드로 이동시킬 수 있다.

---

### **3. 리스트를 실제로 두 개로 분리하려면 `next`를 끊어야 한다**

front list를 만든 후

```c
frontTailP->next = NULL;
```

을 실행해야 한다.

그렇지 않으면 원래 리스트의 연결이 그대로 남아 있기 때문에 front list가 back list까지 이어질 수 있다.

back list 역시 마지막에

```c
backTail->next = NULL;
```

로 끝을 명확하게 끊어준다.

---

### **4. 홀수 개수라면 앞쪽에 하나 더 넣는다**

```c
int mid = (size + 1) / 2;
```

로 계산하면 된다.

```text
size = 5 → front 3개 / back 2개
size = 4 → front 2개 / back 2개
size = 3 → front 2개 / back 1개
```

문제의 조건인 **홀수일 때 extra element를 front list에 넣는 것**을 만족한다. 

---

## **4. 최종 완성 코드**

```c
void frontBackSplitLinkedList(LinkedList *ll, LinkedList *resultFrontList, LinkedList *resultBackList)
{
    /* add your code here */

    ListNode *frontP = resultFrontList->head;
    ListNode *frontTailP = resultFrontList->head;

    ListNode *backP = resultBackList->head;
    ListNode *backTail = resultBackList->head;

    ListNode *start = ll->head;

    int idx = 0;
    int size = ll->size;
    int mid = (size + 1) / 2;

    while (idx < mid) {
        if (frontP == NULL) {
            frontP = start;
            frontTailP = start;
        } else {
            frontTailP->next = start;
            frontTailP = start;
        }

        idx++;
        start = start->next;
    }

    resultFrontList->head = frontP;

    if (frontTailP != NULL) {
        frontTailP->next = NULL;
    }

    while (start != NULL) {
        if (backP == NULL) {
            backP = start;
            backTail = start;
        } else {
            backTail->next = start;
            backTail = start;
        }

        start = start->next;
    }

    resultBackList->head = backP;

    if (backTail != NULL) {
        backTail->next = NULL;
    }
}
```

### **최종 동작 흐름**

```text
원래 리스트

2 → 3 → 5 → 6 → 7


        ↓ frontCount = 3


frontP
  ↓
2 → 3 → 5 → NULL

backP
  ↓
6 → 7 → NULL


결과

Front List: 2 → 3 → 5
Back List : 6 → 7
```

이 문제의 핵심은 **값을 복사해서 새 리스트를 만드는 게 아니라, 기존 노드의 주소를 이용해서 `next` 연결을 재구성하고 마지막에 각 결과 리스트의 `head`를 지정하는 것**이다.
