# 단방향 연결 리스트 정렬 삽입(`insertSortedLL`) 구현

## 1. 문제 요구사항

* **기능**: 정렬된 연결 리스트(`LinkedList`)에 새로운 값(`item`)을 올바른 위치에 오름차순으로 삽입.
* **반환값**:
    * 성공 시: 노드가 삽입된 **인덱스(`idx`)** 반환
    * 실패 시: 리스트에 이미 동일한 값이 존재하면 메모리를 할당하지 않고 **`-1`** 반환


* **예외 조건**:
    * 중복 요소 방지 (중복 시 `-1` 반환 및 메모리 누수 방지)
    * 리스트 크기(`ll->size`) 갱신
    * 경계 조건 처리: **빈 리스트**, **맨 앞 삽입**, **중간 삽입**, **맨 뒤 삽입**

---

## **2. 시행착오 과정**

### **1차 시도: 포인터 연결 순서를 잘못 생각함 + 반환값 누락**

```c
// 1차 시도 주요 에러 코드

if (ll->head->item > item) {

    ll->head = newNode;        // 기존 head를 잃어버림

    newNode->next = ll->head;  // 자기 자신을 가리키게 됨
}

while (curNode != NULL) {

    if (curNode->item > item) {

        newNode->next = curNode;

        prevNode->next = newNode;

        break;                 // break만 하고 return을 안 함
    }

    prevNode = curNode;
    curNode = curNode->next;
}

// 함수가 끝날 때까지 반환값이 제대로 나오지 않고
// ll->size도 증가시키지 않음
```

* **문제점**: 
    * 맨 앞에 넣을 때 `head`를 먼저 `newNode`로 바꿔서 기존 `head`를 가리킬 수가 없었다. 그래서 `newNode->next`에 기존 `head`를 먼저 연결한 다음 `head`를 바꿔야 했다.
    * 그리고 중간에 삽입할 위치를 찾았을 때 `break`만 하고 끝내서 **삽입된 인덱스를 반환하지 못했다.**
    * `ll->size`도 같이 증가시켜야 하는데 이 부분도 빼먹어서, 이후 `findNode`, `removeNode` 같은 함수에서 실제 노드 개수와 `size`가 달라지는 문제가 생겼다.

---

### **2차 시도: `malloc`을 너무 빨리 하고, 맨 뒤 삽입 코드가 실행되지 않음**
```c
// 2차 시도 주요 에러 코드

int insertSortedLL(LinkedList *ll, int item) {

    ListNode *newNode = malloc(sizeof(ListNode)); // 중복 검사 전에 할당

    if (ll->head->item == item) {
        return -1;  // free하지 않고 바로 return
    }

    while (curNode != NULL) {

        if (curNode->item == item)
            return -1;  // 여기서도 메모리 누수

        if (curNode->item > item) {

            // ... 노드 연결 ...

            break;
        }

        prevNode = curNode;
        curNode = curNode->next;
    }

    return 0;  // 무조건 0을 반환

    // 이 코드는 위에서 이미 return했기 때문에 실행되지 않음
    if (curNode == NULL) {

        prevNode->next = newNode;

        ll->size++;

        return 0;
    }
}
```

* **문제점**:

  1. 중복인지 확인하기 전에 `malloc`부터 해버렸다. 중복이라서 `-1`을 반환하면 이미 할당한 메모리를 사용하지도 않고 끝나기 때문에 **메모리 누수**가 발생한다.
  2. `while`문 다음에 `return 0`을 넣어버려서, 그 아래에 있는 **맨 뒤 삽입 코드가 아예 실행되지 않았다.**
  3. 삽입에 성공했을 때 반환해야 하는 건 `0`이 아니라 **실제로 삽입된 위치인 `idx`**였다.

### **3차 시도: `NULL`인 포인터를 바로 사용함**

```c
// 3차 시도 주요 에러 코드

int insertSortedLL(LinkedList *ll, int item) {

    int idx = 0;

    // ... 위치 탐색 ...

    ListNode *newNode = malloc(sizeof(ListNode));

    newNode->item = item;
    newNode->next = curNode;

    prevNode->next = newNode;  // prevNode가 NULL이면 오류 발생

    if (ll->head == NULL) {

        ll->head->item = item; // ll->head도 NULL인데 접근함
    }
}
```

* **문제점**: 
    * `prevNode`가 항상 존재한다고 생각하고 `prevNode->next`에 바로 접근했는데, 빈 리스트거나 맨 앞에 삽입하는 경우에는 `prevNode`가 `NULL`이었다.
    * 그런데 `NULL`인 상태에서 `prevNode->next`에 접근하니까 바로 Segmentation Fault가 발생했다.
    * `ll->head == NULL`인 경우에도 `ll->head->item`에 접근했는데, `head` 자체가 `NULL`이기 때문에 이 방법도 잘못된 방식이었다.

## **3. 깨달음**

1. **`malloc`은 삽입이 확정된 다음에 하기**

   중복인지 먼저 확인하고, 실제로 삽입할 위치까지 찾은 다음에 `malloc`을 해야 불필요하게 메모리를 할당하는 일이 없다.

2. **`prevNode == NULL`로 앞쪽 삽입을 처리할 수 있음**

   `prevNode`가 `NULL`이라는 건 아직 이전 노드가 없다는 뜻이다.

   그래서

   * 리스트가 비어 있는 경우
   * 맨 앞에 삽입하는 경우

   둘 다 `prevNode == NULL`로 처리할 수 있다.

3. **맨 뒤 삽입도 `prevNode`로 처리할 수 있음**

    **`2 3 5 7 8 9`에 `11`을 삽입하는 경우:**

    ```text
    초기 상태

    head
    ↓
    [2] → [3] → [5] → [7] → [8] → [9] → NULL


    11과 비교하면서 순회

    [2] → [3] → [5] → [7] → [8] → [9] → NULL
    ↑                                         
    curNode                                   

    2 < 11 → 다음
    3 < 11 → 다음
    5 < 11 → 다음
    7 < 11 → 다음
    8 < 11 → 다음
    9 < 11 → 다음


    모든 노드를 지나가면

    prevNode
    ↓
    [2] → [3] → [5] → [7] → [8] → [9] → NULL
                                        ↑
                                    prevNode

    curNode == NULL
    ```

    그 다음 `newNode`를 만들고:

    ```text
    newNode
    ↓
    [11] → NULL


    prevNode->next = newNode

    [2] → [3] → [5] → [7] → [8] → [9] → [11] → NULL
                                        ↑       ↑
                                    prevNode  newNode
    ```

    그리고 코드에서는

    ```c
    newNode->next = curNode;
    ```

    인데 현재

    ```c
    curNode == NULL
    ```

    이므로

    ```c
    newNode->next = NULL;
    ```

    이 된다.

    마지막으로

    ```c
    prevNode->next = newNode;
    ```

    를 실행하면 `9` 뒤에 `11`이 연결된다.

    ### 최종 상태

    ```text
    head
    ↓
    [2] → [3] → [5] → [7] → [8] → [9] → [11] → NULL
    ```

    그리고 `idx`는 `0 → 1 → 2 → 3 → 4 → 5 → 6`으로 증가했기 때문에 **`11`이 들어간 인덱스는 `6`**이다.

## **4. 최종 완성 코드**

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct _listnode {
    int item;
    struct _listnode *next;
} ListNode;

typedef struct _linkedlist {
    int size;
    ListNode *head;
} LinkedList;

int insertSortedLL(LinkedList *ll, int item)
{
    int idx = 0;

    ListNode *prevNode = NULL;
    ListNode *curNode = ll->head;

    // 1. 삽입할 위치를 찾으면서 중복 검사
    while (curNode != NULL) {

        // 이미 같은 값이 있으면 삽입하지 않음
        if (curNode->item == item) {
            return -1;
        }

        // 현재 노드보다 작으면 이 위치에 삽입
        if (curNode->item > item) {
            break;
        }

        prevNode = curNode;
        curNode = curNode->next;
        idx++;
    }

    // 2. 중복이 없고 삽입 위치를 찾은 후 노드 생성
    ListNode *newNode = (ListNode *)malloc(sizeof(ListNode));

    newNode->item = item;
    newNode->next = curNode;

    // 3. 노드 연결
    if (prevNode == NULL) {
        // 빈 리스트거나 맨 앞에 삽입하는 경우
        ll->head = newNode;
    }
    else {
        // 중간이나 맨 뒤에 삽입하는 경우
        prevNode->next = newNode;
    }

    // 4. 리스트 크기 증가 후 삽입된 인덱스 반환
    ll->size++;

    return idx;
}
```
