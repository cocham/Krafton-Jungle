# **2개의 단방향 연결 리스트 번갈아 병합(`alternateMergeLinkedList`) 구현**

## **1. 문제 요구사항**

* **기능**: `ll2`의 노드를 `ll1`의 노드 사이에 하나씩 번갈아 삽입하여 `ll1`을 수정.

* **병합 방식**:

    * `ll1`의 노드 다음에 `ll2`의 노드를 하나 삽입
    * 다시 `ll1`의 다음 노드를 연결
    * 이를 반복

    ```text
    LinkedList1: 1 → 2 → 3
    LinkedList2: 4 → 5 → 6 → 7

    결과

    LinkedList1: 1 → 4 → 2 → 5 → 3 → 6
    LinkedList2: 7
    ```

* **구현 방식**:

    * 새로운 리스트를 만드는 것이 아니라 **기존 `ll1`, `ll2`의 노드를 재활용하여 `next`를 직접 변경**
    * 따라서 새로운 노드를 생성하는 `malloc()`은 사용하지 않음

* **예외 조건**:

    * `ll1`의 노드가 먼저 끝나면 `ll2`의 남은 노드는 `ll2`에 그대로 남김
    * `ll2`의 노드가 먼저 끝나면 `ll1`의 남은 노드는 그대로 유지
    * `next`를 변경하기 전에 기존 다음 노드를 저장하여 연결이 끊어지지 않도록 처리

* **핵심 포인터**:

    * `ll1Start`: 현재 `ll1`에서 처리할 노드
    * `ll2Start`: 현재 `ll2`에서 가져올 노드
    * `ll1Next`: `ll1Start`의 원래 다음 노드
    * `ll2Next`: `ll2Start`의 원래 다음 노드
---

# 링크드리스트 2번

## **1. 문제 풀이 방향**

두 개의 링크드리스트를 받아서 노드를 하나씩 번갈아가면서 연결하는 문제였다.

예를 들어

```text
LinkedList1: 1 → 2 → 3
LinkedList2: 4 → 5 → 6 → 7
```

이라면

```text
LinkedList1: 1 → 4 → 2 → 5 → 3 → 6
LinkedList2: 7
```

이렇게 만들어야 한다.

처음에는 `ll3`이라는 새로운 리스트를 만들어서 두 리스트의 값을 복사한 뒤 합치려고 했다.

```text
ll1: A → B → C
ll2: 1 → 2 → 3

ll3: A → 1 → B → 2 → C → 3
```

그런데 문제의 조건을 다시 확인해보니 새로운 리스트를 만드는 게 아니라 **기존 `ll1`과 `ll2`의 노드를 직접 연결하는 방식**이었다.

따라서 새로운 노드를 `malloc()`으로 만들 필요가 없고, 기존 노드들의 `next`만 변경하면 된다. 

---

## **2. 시행착오 과정**

### **1차 시도: 새로운 리스트를 만들어서 병합하려고 함**

처음에는 `ll3`을 새로 만들고 `ll1`, `ll2`의 노드를 복사해서 번갈아 연결하려고 했다.

```c
LinkedList ll3;
ll3.head = NULL;
ll3.size = 0;
```

그리고 각각의 노드를 새로 할당했다.

```c
ListNode *newNodeFromL1 = malloc(sizeof(ListNode));
ListNode *newNodeFromL2 = malloc(sizeof(ListNode));
```

여기서 `malloc(sizeof(ll1Start))`도 사용했는데, `ll1Start`는 `ListNode *`이기 때문에 `sizeof(ll1Start)`는 **노드의 크기가 아니라 포인터의 크기**를 구하게 된다.

따라서 노드 하나를 할당하려면

```c
malloc(sizeof(ListNode))
```

를 사용해야 한다. 

---

### **`while` 조건도 잘못 작성함**

처음에는

```c
while (ll1Start->next != NULL & ll2Start->next != NULL)
```

으로 작성했다.

여기에는 두 가지 문제가 있었다.

첫 번째는 `&`가 아니라 `&&`를 사용해야 한다는 것이다.

```c
while (ll1Start->next != NULL && ll2Start->next != NULL)
```

두 번째는 `next`를 검사하면 마지막 노드를 처리하지 못한다는 것이다.

예를 들어

```text
A → B → C → NULL
```

에서 `C`까지 왔을 때

```c
C->next == NULL
```

이므로 반복문이 끝난다.

그러면 `C`를 복사하거나 처리할 기회가 없어진다.

그래서 **현재 노드가 존재하는지**를 검사하도록 바꿨다.

```c
while (ll1Start != NULL && ll2Start != NULL)
```



---

### **새로운 노드를 연결하는 방법에서 실수**

새 노드를 만들어 놓고 `else`에서

```c
ll3Start->next = ll1Start->item;
ll3Start->next->next = ll2Start->item;
```

처럼 작성했다.

그런데 `ll3Start->next`는 `ListNode *`이고 `item`은 `int`라서 타입이 맞지 않는다.

이미 새 노드를 만들어 놓았기 때문에 `item`이 아니라 **노드 자체를 연결**해야 한다.

```c
ll3Start->next = newNodeFromL1;
newNodeFromL1->next = newNodeFromL2;
ll3Start = newNodeFromL2;
```

이렇게 하면

```text
A → 1 → B → 2 → C → 3
                    ↑
                ll3Start
```

처럼 `ll3Start`가 현재 리스트의 마지막 노드를 계속 가리킬 수 있다. 

---

### **남는 노드는 따로 처리**

두 리스트의 길이가 다를 수 있기 때문에 둘 중 하나가 먼저 끝난 뒤 남는 노드도 처리해야 했다.

그래서 각각 별도의 `while`문을 사용했다.

```c
while (ll1Start != NULL) {
    ...
}

while (ll2Start != NULL) {
    ...
}
```

처음에는 여기서 `ll3Start`를 갱신하지 않아서 문제가 생겼다.

```c
ll3Start->next = newNodeFromL1;

ll1Start = ll1Start->next;
```

이렇게만 하면 새로 추가한 노드로 `ll3Start`가 이동하지 않는다.

따라서

```c
ll3Start = newNodeFromL1;
```

도 같이 해줘야 한다.



---

## **3. 새로운 리스트를 만드는 방식의 문제**

코드를 어느 정도 완성했지만, 다시 문제 조건을 확인해보니 접근 자체가 잘못되어 있었다.

내가 만든 방식은

```text
ll1 + ll2
   ↓
새로운 ll3 생성
```

이었는데 문제에서 원하는 것은

```text
ll1의 기존 노드
      +
ll2의 기존 노드
      ↓
ll1을 직접 변경
```

하는 것이었다.

따라서 `malloc()`을 사용해서 새로운 노드를 만드는 것도 필요하지 않았다.

또한 함수 안에서 만든 `ll3`은 지역 변수이기 때문에 함수가 끝나면 사라진다.

결과적으로 `ll1`과 `ll2`에는 병합 결과가 반영되지 않는다.

그리고 `malloc()`으로 만든 노드들도 따로 관리하지 않기 때문에 메모리 누수까지 발생한다. 

---

## **4. 2차 시도: 기존 노드를 직접 연결**

새로운 리스트를 만들지 않고 기존 노드를 직접 연결하는 방향으로 다시 작성했다.

내가 생각한 구조는

```text
ll1: 1 → 2 → 3
ll2: 4 → 5 → 6 → 7

1 → 4 → 2 → 5 → 3 → 6
```

이었다.

그래서 처음에는 단순하게

```c
ll1Start->next = ll2Start;
ll2Start = ll2Start->next;
ll1Start = ll1Start->next->next;
```

처럼 작성했다.

그런데 여기서 문제가 발생했다.

---

### **`next`를 덮어쓰기 전에 저장해야 함**

```c
ll1Start->next = ll2Start;
```

를 하는 순간 원래 `ll1Start->next`가 가리키던 노드를 잃어버린다.

예를 들어

```text
1 → 2 → 3
```

에서

```c
1->next = 4;
```

를 해버리면

```text
1 → 4

2 → 3
```

이 된다.

따라서 `2`로 이동하려면 **덮어쓰기 전에 기존 `next`를 저장해놔야 한다.**

```c
ListNode *ll1Next = ll1Start->next;
ListNode *ll2Next = ll2Start->next;
```

그리고 나서 연결을 변경한다.

```c
ll1Start->next = ll2Start;
ll2Start->next = ll1Next;
```

결과적으로

```text
1 → 4 → 2 → 3
```

이 된다. 

---

### **`ll2Start`도 다음 노드로 이동해야 함**

처음에는

```c
ListNode *ll2Next = ll2Start->next;
```

까지는 해놓고 실제로 `ll2Start`를 이동시키는 것을 빠뜨렸다.

```c
ll1Start = ll1Next;
```

만 작성되어 있었는데, 이렇게 하면 다음 반복에서도 `ll2Start`가 계속 같은 노드를 가리키게 된다.

따라서

```c
ll2Start = ll2Next;
```

도 필요하다.

최종적으로 한 번의 반복은 다음과 같이 된다.

```c
ListNode *ll1Next = ll1Start->next;
ListNode *ll2Next = ll2Start->next;

ll1Start->next = ll2Start;
ll2Start->next = ll1Next;

ll1Start = ll1Next;
ll2Start = ll2Next;
```



---

## **5. 최종 풀이**

최종적으로는 새로운 노드를 만들지 않고, 기존 노드들의 `next`만 변경하는 방식으로 해결했다.

```c
void alternateMergeLinkedList(LinkedList *ll1, LinkedList *ll2)
{
    ListNode* ll1Start = ll1->head;
    ListNode* ll2Start = ll2->head;

    while (ll1Start != NULL && ll2Start != NULL) {
        ListNode *ll1Next = ll1Start->next;
        ListNode *ll2Next = ll2Start->next;

        ll1Start->next = ll2Start;
        ll2Start->next = ll1Next;

        ll1Start = ll1Next;
        ll2Start = ll2Next;
    }
}
```

핵심은 **연결을 바꾸기 전에 기존 `next`를 저장하는 것**이다.

```text
원래

1 → 2 → 3
4 → 5 → 6 → 7


1. 기존 next 저장

1 → 2
4 → 5

ll1Next = 2
ll2Next = 5


2. 연결 변경

1 → 4 → 2
4 → 2


3. 포인터 이동

ll1Start → 2
ll2Start → 5


다음 반복

2 → 5 → 3
```

이 과정을 반복하면 최종적으로

```text
ll1

1 → 4 → 2 → 5 → 3 → 6


ll2

7
```

이 된다.

결국 이 문제에서 가장 중요했던 건 **새로운 리스트를 만드는 것이 아니라 기존 노드의 연결 관계를 직접 변경하는 것**, 그리고 **`next`를 덮어쓰기 전에 다음 노드를 미리 저장하는 것**이었다.
